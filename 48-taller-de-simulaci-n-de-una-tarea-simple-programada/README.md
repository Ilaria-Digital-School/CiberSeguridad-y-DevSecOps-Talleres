# Taller de : simulación de una tarea simple programada

**Recordatorio teórico** En Python, una tarea programada (o 'scheduled task') consiste en ejecutar automáticamente un bloque de código en intervalos regulares o a una hora determinada. En el contexto de la ciberseguridad, este mecanismo es fundamental: los atacantes lo utilizan para mantener persistencia en un sistema comprometido, y los defensores lo emplean para automatizar auditorías periódicas (escaneos de puertos, comprobación de integridad de archivos, monitoreo de logs). La simulación de una tarea programada en Python sin librerías externas se construye sobre tres pilares ya estudiados: las condiciones (if/else) para tomar decisiones, los bucles (while/for) para repetir acciones en el tiempo, y los argumentos de línea de comandos para hacer el script configurable. El módulo estándar `time` (especialmente `time.sleep(segundos)`) permite introducir pausas controladas entre iteraciones, simulando así intervalos de ejecución. El módulo `datetime` permite obtener la hora actual y formatearla. Error frecuente: confundir `time.sleep(60)` (pausa de 60 segundos) con una verdadera tarea programada del sistema operativo (cron, Task Scheduler). En este taller simulamos el comportamiento, no reemplazamos el planificador del sistema. Mini-ejemplo mental: un bucle `while True` que cada 10 segundos imprime la hora actual y verifica una condición representa la estructura mínima de una tarea periódica simulada. --- **Enunciado del taller** En este taller construirás un script Python que simule el comportamiento de una tarea programada de seguridad. El contexto profesional es el siguiente: como analista DevSecOps, necesitas un pequeño agente autónomo que se ejecute periódicamente para comprobar si un conjunto de puertos específicos está accesible en una máquina objetivo...
