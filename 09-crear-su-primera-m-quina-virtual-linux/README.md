# Crear su primera máquina virtual Linux

Recordatorio teórico: Fundamentos de la virtualización Una máquina virtual (VM) es un sistema informático virtualizado que funciona como un ordenador completo dentro de su ordenador físico real, llamado host. El software que gestiona las máquinas virtuales se denomina hipervisor. Hyper-V, VirtualBox y VMware Workstation Player son ejemplos de hipervisores de tipo 2, que se ejecutan sobre un sistema operativo existente. El modelo mental clave es la abstracción: el hipervisor traduce las instrucciones y el acceso a recursos de hardware físico (CPU, RAM, disco) en recursos virtuales asignados a la máquina virtual. Un error frecuente es asignar recursos excesivos a la VM, como más del 50% de la RAM disponible del host, lo que puede degradar el rendimiento de ambos sistemas. Otro error común es seleccionar un modo de red incorrecto; el modo NAT permite a la VM acceder a internet sin que sea visible desde la red externa, mientras que el modo puente la hace aparecer como un dispositivo más en su red local. Un mini-ejemplo ilustrativo: si su ordenador host tiene 16 GB de RAM y 8 núcleos de CPU, podría asignar de forma segura 4 GB de RAM (unos 4096 MB) y 2 núcleos de CPU a su máquina virtual Linux. Esto permite que la VM funcione correctamente mientras el host mantiene suficientes recursos para operar.
