# Taller: crear hello.py configurable

**Recordatorio teórico** En los capítulos anteriores has trabajado con variables, tipos de datos, conversiones, condiciones, bucles y argumentos de línea de comandos. Este taller reúne todos esos conceptos en un único script funcional y configurable. Un script Python ejecutable recibe parámetros externos a través de sys.argv, lo que le permite comportarse de forma diferente según lo que el usuario indique al lanzarlo. Por ejemplo, `python hello.py Alice 8080` pasa dos argumentos: un nombre y un número de puerto. Dentro del script, sys.argv[0] es siempre el nombre del propio fichero, sys.argv[1] sería 'Alice' y sys.argv[2] sería '8080' (como cadena de texto, no como entero). Error frecuente: olvidar convertir los argumentos numéricos con int() antes de compararlos. Otro error habitual es no verificar cuántos argumentos se han pasado antes de acceder a ellos, lo que provoca un IndexError. Modelo mental: un script configurable es como una función con parámetros, pero esos parámetros vienen del terminal. Siempre debes: (1) comprobar que existen los argumentos esperados, (2) convertirlos al tipo adecuado, (3) aplicar la lógica de negocio con condiciones o bucles, y (4) mostrar un mensaje claro al usuario.
