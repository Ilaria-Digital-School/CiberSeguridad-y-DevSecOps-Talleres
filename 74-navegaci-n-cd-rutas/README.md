# Navegación (cd, rutas)

**RECORDATORIO TEÓRICO** En Linux, el sistema de archivos se organiza como un árbol invertido cuya raíz es '/'. Cada archivo y directorio tiene una ubicación precisa expresada mediante una ruta. Existen dos tipos de rutas: la ruta absoluta, que siempre comienza con '/' y describe el camino completo desde la raíz (por ejemplo, /home/usuario/documentos), y la ruta relativa, que describe el camino desde el directorio actual (por ejemplo, ../documentos o proyectos/web). El comando 'cd' (change directory) permite desplazarse entre directorios. Algunos atajos esenciales: 'cd ~' lleva al directorio home del usuario, 'cd ..' sube un nivel, 'cd -' regresa al directorio anterior, y 'cd /' va directamente a la raíz. El carácter '.' representa el directorio actual y '..' representa el directorio padre. Un error frecuente en principiantes es confundir rutas absolutas con relativas, lo que genera mensajes del tipo 'No such file or directory'. Por ejemplo, si estás en /home/usuario y ejecutas 'cd documentos', Linux buscará /home/usuario/documentos (ruta relativa). Si ejecutas 'cd /documentos', buscará una carpeta 'documentos' directamente en la raíz, lo que generará un error si no existe. Comprender esta distinción es fundamental en ciberseguridad, ya que explorar sistemas de archivos durante un pentest o una auditoría exige navegar con precisión y eficiencia. --- **ENUNCIADO DEL TALLER** Este taller tiene como objetivo consolidar tu capacidad de navegar por el sistema de archivos de Linux utilizando el comando 'cd' y dominando tanto las rutas absolutas como las relativas.
