# Calcular el rango de direcciones /24 y /26

**Recordatorio teórico** Una dirección IP versión 4 está compuesta por 32 bits, habitualmente representados en cuatro octetos decimales separados por puntos (por ejemplo, 192.168.1.0). La notación CIDR (Classless Inter-Domain Routing) añade un sufijo que indica cuántos bits de esos 32 son la parte de red. Así, /24 significa que los primeros 24 bits identifican la red y los 8 bits restantes identifican los hosts; /26 significa 26 bits de red y 6 bits de host. El número de direcciones totales de una subred se calcula con la fórmula 2^(32 - prefijo). Para /24 obtienes 2^8 = 256 direcciones; para /26 obtienes 2^6 = 64 direcciones. De ese total, siempre se restan 2 direcciones reservadas: la dirección de red (primer extremo) y la dirección de broadcast (último extremo). Los hosts utilizables son, por tanto, 254 para /24 y 62 para /26. Error frecuente: confundir la máscara de subred con el rango de hosts. La máscara /24 equivale a 255.255.255.0 y la /26 equivale a 255.255.255.192. Otro error habitual es olvidar que una red /26 divide un espacio /24 en exactamente 4 subredes de 64 direcciones cada una. Mini-ejemplo: para la red 10.0.0.0/26, el rango completo va de 10.0.0.0 a 10.0.0.63; la dirección de red es 10.0.0.0, el broadcast es 10.0.0.63 y los hosts utilizables son 10.0.0.1 a 10.0.0.62. --- **Enunciado del taller** Este taller tiene como objetivo consolidar tu comprensión práctica del direccionamiento IP con notación CIDR, una habilidad fundamental en ciberseguridad y DevSecOps.
