# Analiza una salida de traceroute

**RECORDATORIO TEÓRICO** Traceroute (o tracert en Windows) es una herramienta de diagnóstico de red que permite visualizar la ruta que siguen los paquetes IP desde tu máquina hasta un destino, pasando por cada enrutador intermedio (llamado 'salto' o 'hop'). Funciona enviando paquetes con un valor TTL (Time To Live) incrementado progresivamente: el primer paquete tiene TTL=1, el segundo TTL=2, etc. Cada enrutador que recibe un paquete con TTL=0 responde con un mensaje ICMP 'Time Exceeded', revelando así su dirección IP y el tiempo de respuesta. Cada línea de la salida de traceroute representa un salto e indica: el número de salto, el nombre de host (si está disponible), la dirección IP del enrutador y tres tiempos de latencia en milisegundos (correspondientes a tres sondas enviadas). Un asterisco (*) en lugar de un tiempo indica que el enrutador no respondió o que filtró la sonda, lo que puede deberse a un firewall, una política de seguridad o una pérdida de paquetes. Errores frecuentes: confundir un asterisco con un fallo total del enrutador (puede simplemente no responder a ICMP pero seguir enrutando el tráfico), interpretar una latencia alta en un salto intermedio como un cuello de botella real (los enrutadores priorizan el tráfico de tránsito sobre las respuestas ICMP), o ignorar los cambios de prefijo de red como indicadores de cambio de proveedor (AS).
