# Instalar un software de virtualización en su ordenador

Recordatorio teórico La virtualización es una tecnología fundamental en la ciberseguridad que permite crear máquinas virtuales dentro de un ordenador físico. Esta máquina anfitriona ejecuta un software especial llamado hipervisor, que gestiona los recursos asignados a cada máquina virtual invitada. Cada invitada opera como un sistema independiente, con su propio sistema operativo y aplicaciones, aislada del sistema anfitrión y de otras máquinas virtuales. El modelo mental clave es concebir una capa de abstracción entre el hardware físico y los sistemas operativos. Este laboratorio aislado es esencial para practicar técnicas de ataque y defensa sin tocar sistemas reales. Un error frecuente es no verificar la compatibilidad del hardware ni habilitar las extensiones de virtualización en la BIOS, lo que provoca el fallo de la instalación. Por ejemplo, imagine un ordenador con 16 GB de RAM y un procesador de cuatro núcleos. Usted puede asignar recursos virtuales a varias máquinas: una con 4 GB de RAM y dos núcleos para una máquina con Kali Linux, otra con 2 GB y un núcleo para una máquina con Metasploitable, y aún le quedarían recursos para el sistema operativo anfitrión. Este esquema le permite tener múltiples sistemas interactuando en una red segura y controlada. Enunciado del taller Este taller práctico tiene un objetivo concreto y fundamental: instalar un software de virtualización funcional en su propio ordenador. Esta herramienta será la piedra angular de su laboratorio personal para todas las prácticas posteriores en ciberseguridad.
