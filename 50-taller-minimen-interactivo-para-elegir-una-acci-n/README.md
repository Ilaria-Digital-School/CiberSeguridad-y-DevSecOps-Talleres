# Taller: minimenú interactivo para elegir una acción

**Recordatorio teórico** En Python, un menú interactivo combina varios conceptos fundamentales que ya has trabajado: variables, bucles, condiciones y funciones. La idea central es presentar al usuario una lista de opciones numeradas, capturar su elección con la función input(), validar esa entrada y ejecutar la acción correspondiente mediante una estructura if/elif/else o, a partir de Python 3.10, con match/case. El bucle while es el mecanismo habitual para mantener el menú activo hasta que el usuario decida salir, típicamente eligiendo una opción de tipo 'q' o '0'. Un error frecuente es olvidar convertir la entrada del usuario (que siempre es una cadena de texto) al tipo entero con int(), lo que provoca comparaciones incorrectas. Otro error común es no gestionar entradas inválidas, lo que hace que el programa se rompa con una excepción ValueError. La solución es envolver la conversión en un bloque try/except. Mini-ejemplo: si el usuario escribe '2' y tú comparas directamente con el entero 2 sin conversión, la condición nunca será verdadera. Recuerda también encapsular cada acción del menú en su propia función, lo que hace el código más limpio, reutilizable y fácil de mantener, siguiendo el principio de separación de responsabilidades que es esencial en la automatización de seguridad. --- **Enunciado del taller** En este taller construirás un script Python llamado menu.py que implemente un minimenú interactivo orientado a tareas de reconocimiento de red, un escenario muy habitual en ciberseguridad ofensiva y defensiva.
