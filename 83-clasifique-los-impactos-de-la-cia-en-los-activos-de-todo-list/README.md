# Clasifique los impactos de la CIA en los activos de Todo List

Recordatorio teórico La tríada CIA (Confidencialidad, Integridad y Disponibilidad) es el modelo mental fundamental para evaluar la seguridad de cualquier activo. La Confidencialidad garantiza que solo las personas autorizadas accedan a la información; la Integridad asegura que los datos no sean alterados de forma no autorizada; la Disponibilidad garantiza que el activo esté accesible cuando se necesita. Un activo es todo elemento con valor para la aplicación o sus usuarios: datos, credenciales, funciones o infraestructura. Un impacto es la consecuencia negativa que sufre un activo cuando una de estas tres propiedades es vulnerada. El error frecuente de los principiantes es confundir las tres propiedades: por ejemplo, tratar un robo de datos (fallo de Confidencialidad) como si fuera una alteración (fallo de Integridad). Otro error habitual es asignar impactos uniformes a todos los activos, sin diferenciar su valor real. Recuerda: no todos los activos merecen la misma protección; priorizar es la clave del modelado de amenazas. Mini-ejemplo: en una aplicación de Todo List, el activo «contraseña del usuario» tiene un impacto de Confidencialidad Alto (si se filtra, comprometería la cuenta), un impacto de Integridad Medio y un impacto de Disponibilidad Bajo. En cambio, el activo «lista de tareas» podría tener un impacto de Disponibilidad Medio, ya que su indisponibilidad temporal molesta pero no es catastrófica. Clasificar correctamente estos impactos permite priorizar las pruebas y correcciones de seguridad más adelante.
