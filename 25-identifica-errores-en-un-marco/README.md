# Identifica errores en un marco

RECORDATORIO TEÓRICO Una trama Ethernet (marco) es la unidad de datos de la capa 2 del modelo OSI. Está compuesta por campos bien definidos: el preámbulo (7 bytes de sincronización), el delimitador de inicio de trama SFD (1 byte), la dirección MAC de destino (6 bytes), la dirección MAC de origen (6 bytes), el campo EtherType/longitud (2 bytes), los datos de carga útil (46 a 1500 bytes) y el FCS —Frame Check Sequence— (4 bytes), que es el campo de detección de errores calculado mediante CRC. Cada campo tiene un tamaño y formato estrictos: cualquier desviación constituye un error. Los errores más frecuentes en una trama son: direcciones MAC malformadas o con formato incorrecto (número incorrecto de octetos, caracteres inválidos), un campo EtherType desconocido o incoherente con el contenido, una carga útil inferior al mínimo (menos de 46 bytes sin relleno, generando un 'runt frame'), una carga útil superior al máximo ('giant frame'), o un FCS incorrecto que indica corrupción de datos. Error frecuente de comprensión: confundir la dirección MAC de origen con la de destino, o pensar que el FCS es opcional. El FCS es obligatorio y es calculado por el emisor; si no coincide con el recálculo del receptor, la trama se descarta. Ejemplo mental: imagina una carta postal con remitente, destinatario, contenido y un código de verificación al final. Si el código no coincide con el contenido, el cartero tira la carta.
