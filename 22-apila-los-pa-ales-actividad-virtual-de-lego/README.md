# Apila los pañales (actividad virtual de Lego)

RECORDATORIO TEÓRICO El modelo OSI (Open Systems Interconnection) es un marco conceptual de 7 capas que describe cómo los datos viajan desde una aplicación en un dispositivo hasta otra aplicación en otro dispositivo, pasando por la red física. Cada capa tiene una responsabilidad precisa y se comunica únicamente con las capas adyacentes. De arriba hacia abajo: Aplicación (7), Presentación (6), Sesión (5), Transporte (4), Red (3), Enlace de datos (2) y Física (1). El proceso por el cual los datos descienden por estas capas añadiendo encabezados (y a veces colas) se llama encapsulación. Al subir en el destino, el proceso inverso se denomina desencapsulación. Un error frecuente en principiantes es confundir el rol de la capa de Red (que gestiona el direccionamiento IP y el enrutamiento entre redes) con el de la capa de Enlace de datos (que gestiona la entrega dentro de una misma red local mediante direcciones MAC). Otro error habitual es creer que cada capa 've' el contenido completo del mensaje: en realidad, cada capa solo procesa su propio encabezado y trata el resto como datos opacos (payload). Mini-ejemplo mental: imagina que escribes una carta (Capa 7), la metes en un sobre con el nombre del destinatario (Capa 4 añade el puerto), luego escribes la dirección IP en el sobre (Capa 3), lo entregas al cartero local que conoce la dirección física de tu calle (Capa 2), y finalmente el cartero la transporta por carretera (Capa 1).
