# Chown y chgrp

Recordatorio teórico: En Linux, cada archivo y directorio tiene un propietario (usuario) y un grupo asociado. Mientras que chmod define qué se puede hacer (leer, escribir, ejecutar), chown y chgrp definen quién es el dueño de esos derechos. El comando 'chown' cambia el propietario de un archivo y, opcionalmente, también el grupo mediante la sintaxis 'chown usuario:grupo archivo'. El comando 'chgrp' se limita a cambiar únicamente el grupo. El modelo mental es sencillo: piense en un archivo como un documento con una etiqueta de dueño y una etiqueta de equipo. chown reasigna la etiqueta de dueño; chgrp reasigna la etiqueta de equipo. La opción '-R' aplica el cambio de forma recursiva a todo un directorio y su contenido, algo esencial para gestionar árboles completos. Errores frecuentes: olvidar que estas operaciones normalmente requieren privilegios de root (sudo), confundir el separador ':' entre usuario y grupo, o aplicar '-R' sin verificar el árbol de destino, provocando cambios masivos irreversibles. Otro error habitual es cambiar el propietario de archivos de sistema o de servicios, rompiendo permisos que un demonio necesita. Mini-ejemplo: si desea que el archivo 'informe.txt' pertenezca al usuario 'ana' y al grupo 'auditores', ejecuta 'sudo chown ana:auditores informe.txt'. Para cambiar solo el grupo de todos los archivos de un directorio: 'sudo chgrp -R auditores /var/datos'. Estos comandos son la base de la gestión de la propiedad, fundamental en cualquier estrategia de control de acceso y endurecimiento (hardening) de un sistema.
