# Identifique las interfaces y los puertos abiertos

RECORDATORIO TEÓRICO En Linux, una interfaz de red es el punto de conexión entre la máquina y una red (física o virtual). Cada interfaz posee un nombre (por ejemplo, lo para el bucle local, eth0 o enp0s3 para Ethernet, wlan0 para Wi-Fi) y puede tener asignadas una o varias direcciones IP. Un puerto es un número (0-65535) asociado a un protocolo de transporte (TCP o UDP) que identifica un servicio en escucha. Cuando un proceso abre un puerto en estado LISTEN, acepta conexiones entrantes; ese puerto se convierte en una posible superficie de ataque. El modelo mental clave es este: interfaz (¿dónde escucho?) + puerto (¿en qué número?) + proceso (¿quién escucha?) + estado (LISTEN, ESTABLISHED). Herramientas como 'ip addr' muestran interfaces y direcciones; 'ss -tulnp' (o el antiguo 'netstat -tulnp') muestra puertos en escucha, protocolos y el proceso asociado. La bandera 0.0.0.0 significa "todas las interfaces", mientras que 127.0.0.1 restringe el servicio al equipo local. Errores frecuentes: confundir un puerto abierto con un puerto en escucha, olvidar ejecutar 'ss' con privilegios para ver el nombre del proceso (-p), o no distinguir entre escucha en localhost y escucha pública. Mini-ejemplo: 'ss -tlnp | grep 22' revela sshd escuchando en el puerto 22/TCP; si aparece en 0.0.0.0:22, el servicio SSH es accesible desde toda la red, lo que debe justificarse por seguridad. --- ENUNCIADO DEL WORKSHOP En este taller asumirás el papel de un analista de seguridad que realiza un reconocimiento del propio sistema (host local).
