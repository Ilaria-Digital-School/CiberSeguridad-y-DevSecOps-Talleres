# Moverse por la estructura de directorios y describirla

Recordatorio teórico: Navegación y estructura del sistema de archivos de Linux En Linux, el sistema de archivos se organiza como un árbol jerárquico de directorios que parten de un único directorio raíz, simbolizado por una barra (/). Este diseño, denominado Estándar de Jerarquía del Sistema de Archivos (FHS), define la ubicación y el propósito de cada directorio principal para garantizar la consistencia entre distribuciones. El directorio raíz es el origen de todo. Los directorios como /bin (binarios esenciales del sistema), /etc (archivos de configuración), /home (directorios de usuario) y /usr (recursos de software de usuario) se ramifican desde él. El modelo mental clave es visualizar este árbol invertido o un organigrama: usted siempre está ubicado en una rama específica (directorio de trabajo) y puede moverse hacia arriba (al directorio padre) o hacia abajo (a subdirectorios). Un error frecuente es confundir las rutas absolutas con las relativas. Una ruta absoluta siempre comienza desde la raíz (/), por ejemplo, /home/usuario/documentos. Una ruta relativa parte de su directorio actual, por ejemplo, documentos/proyecto si ya está en /home/usuario. Otro error común es olvidar que espacios o caracteres especiales en los nombres de archivos deben escaparse o escribirse entre comillas. Mini-ejemplo: desde su directorio personal /home/alumno, el comando `cd /usr/share` lo lleva directamente al directorio share (ruta absoluta). Si luego ejecuta `cd doc`, entrará en /usr/share/doc (ruta relativa). Para volver a su directorio personal, puede usar `cd` sin argumentos o `cd ~`.
