# Hilo rojo: creación de una matriz de amenazas completa para el blog

## Contexto A lo largo de este capítulo has aprendido a identificar componentes y activos, a aplicar la tríada CIA (Confidencialidad, Integridad, Disponibilidad), a utilizar el método STRIDE, a construir Diagramas de Flujo de Datos (DFD) y a cruzar estos conceptos con OWASP. Ahora vas a consolidar todo ello en un único entregable profesional: una **matriz de amenazas completa** para una aplicación de tipo blog. ## Descripción del proyecto Se te entrega (o vas a modelar) una aplicación de blog con las funcionalidades habituales: registro e inicio de sesión de usuarios, creación/edición/eliminación de publicaciones, publicación de comentarios, gestión de sesiones, un panel de administración y una API REST para crear publicaciones. Tu misión es realizar un **modelado de amenazas de extremo a extremo** y producir una matriz de amenazas estructurada, priorizada y accionable. Este proyecto es el 'hilo rojo' del capítulo: reúne todas las competencias trabajadas en los cuestionarios y ejercicios anteriores (componentes/activos/CIA, STRIDE, DFD, OWASP) en un caso concreto y coherente. ## Competencias a validar - Identificar los componentes, los activos y las fronteras de confianza de una aplicación. - Construir un DFD correcto y legible. - Aplicar sistemáticamente STRIDE a cada elemento del DFD. - Evaluar cada amenaza según su impacto sobre la tríada CIA. - Priorizar las amenazas mediante una puntuación de riesgo. - Vincular cada amenaza con las categorías OWASP correspondientes y proponer contramedidas. ## Alcance El proyecto debe cubrir al menos: el flujo de autenticación, la creación de publicaciones (interfaz web y punto final de...
