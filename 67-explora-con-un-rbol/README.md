# Explora con un árbol

**Recordatorio teórico** En Linux, el sistema de archivos se organiza como un árbol jerárquico cuya raíz es '/'. Cada directorio es un nodo que puede contener archivos y otros directorios (subdirectorios), formando ramas que se extienden hacia abajo. Esta estructura es fundamental en ciberseguridad: conocer la disposición del sistema de archivos permite identificar dónde residen los binarios del sistema (/bin, /usr/bin), los archivos de configuración (/etc), los logs (/var/log), los archivos temporales (/tmp) o los directorios de usuarios (/home). La herramienta 'tree' permite visualizar esta estructura de forma gráfica en la terminal, mostrando la jerarquía de directorios y archivos con sangría. El comando 'find' complementa esta exploración al permitir búsquedas avanzadas por nombre, tipo, permisos o fecha de modificación. Un error frecuente en principiantes es confundir rutas absolutas (que siempre parten de '/') con rutas relativas (que parten del directorio actual). Mini-ejemplo: ejecutar 'tree /etc -L 2' muestra los dos primeros niveles del directorio de configuración del sistema, revelando qué servicios están instalados y configurados.
