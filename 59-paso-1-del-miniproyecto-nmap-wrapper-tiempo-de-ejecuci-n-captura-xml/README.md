# Paso 1 del miniproyecto: Nmap wrapper (tiempo de ejecución + captura XML)

## Descripción del proyecto En este primer paso del miniproyecto, el estudiante deberá desarrollar un **wrapper Python para Nmap** que automatice el lanzamiento de escaneos de red, mida el tiempo de ejecución y capture los resultados en formato XML para su posterior procesamiento. Este proyecto constituye la base de un conjunto de herramientas de automatización de seguridad que se irá ampliando a lo largo del curso. La capacidad de envolver herramientas de línea de comandos como Nmap con Python es una competencia esencial para cualquier especialista en ciberseguridad y DevSecOps. ## Contexto profesional En un entorno real de pentest o auditoría de seguridad, los profesionales necesitan automatizar el reconocimiento de infraestructuras, recopilar resultados de forma estructurada y poder procesarlos programáticamente. Nmap es una de las herramientas más utilizadas en esta fase de reconocimiento, y saber controlarlo desde Python permite integrar los resultados en pipelines de análisis más complejos. ## Competencias validadas - Invocar un proceso del sistema operativo desde Python usando el módulo `subprocess` - Medir y formatear tiempos de ejecución con el módulo `datetime` y/o `time` - Capturar la salida XML de Nmap y guardarla en un fichero - Parsear un fichero XML con el módulo `xml.etree.ElementTree` o `minidom` - Estructurar un script Python modular y reutilizable - Gestionar errores y casos límite (host inalcanzable, permisos insuficientes, etc.) ## Entregables esperados 1. **Script Python** (`nmap_wrapper.py`): script funcional y comentado 2. **Fichero XML de ejemplo** generado por el wrapper durante las pruebas 3. **Fichero de informe** (`rapport_execution.txt` o `.md`) con...
