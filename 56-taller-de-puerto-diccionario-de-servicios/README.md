# Taller de : puerto → diccionario de servicios

**Recordatorio teórico** Un diccionario en Python es una estructura de datos que almacena pares clave-valor, lo que lo convierte en la herramienta ideal para asociar un número de puerto con el nombre del servicio que corre sobre él. A diferencia de una lista, donde se accede a los elementos por índice, en un diccionario se accede por clave, lo que permite búsquedas instantáneas y un código mucho más legible. La sintaxis básica es: `servicios = {80: 'HTTP', 443: 'HTTPS', 22: 'SSH'}`. Para acceder a un valor se usa `servicios[80]`, y para evitar errores cuando la clave no existe, se recomienda usar `servicios.get(puerto, 'Desconocido')`, que devuelve un valor por defecto en lugar de lanzar un `KeyError`. Un error frecuente entre principiantes es confundir el tipo de la clave: los puertos son enteros (`int`), no cadenas de texto (`str`). Así, `servicios[80]` y `servicios['80']` son claves distintas. Otro error habitual es intentar acceder a una clave inexistente sin usar `.get()`, lo que provoca un fallo en tiempo de ejecución. El modelo mental correcto es pensar en el diccionario como una 'agenda telefónica': buscas por nombre (clave) y obtienes el número (valor). En el contexto de la ciberseguridad, esta estructura es fundamental para interpretar los resultados de un escaneo de puertos de forma inmediata y automatizada, tal como lo hace Nmap internamente. --- **Enunciado del taller** En los talleres anteriores has trabajado con listas de puertos y con el módulo `subprocess` para lanzar comandos del sistema.
