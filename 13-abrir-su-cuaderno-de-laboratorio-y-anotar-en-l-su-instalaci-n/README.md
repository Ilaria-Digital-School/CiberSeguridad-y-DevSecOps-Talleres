# Abrir su cuaderno de laboratorio y anotar en él su instalación

Recordatorio teórico: La ciencia y el hábito del registro En ciberseguridad, el laboratorio es un entorno aislado, seguro y controlado donde se simulan infraestructuras y ataques para aprender. El cuaderno de laboratorio es la bitácora técnica donde se registra el estado del sistema, cada manipulación realizada, las observaciones y los resultados. Este documento se convierte en una fuente de verdad para usted, el técnico, y para otros profesionales que puedan necesitar comprender o replicar el entorno. Un modelo mental clave es considerar el laboratorio como una 'fotografía reproducible'. No basta con saber que algo funciona; debe poder documentar cómo y por qué, con datos precisos. Un error frecuente es registrar solo los comandos exitosos, omitiendo versiones de software, configuración de red o estados de las instantáneas, lo que hace irreproducible un experimento. Mini-ejemplo: tras instalar un sistema, anotar 'instalé Debian' es insuficiente. Una anotación útil sería: 'Máquina virtual: VirtualBox 7.0. Sistema Debian 12 (kernel 6.1.0-18-amd64). IP estática: 192.168.56.10/24. Estado post-instalación, antes de instalar metasploitable2. Instantánea: Debian 12 - Base limpia'. Documentar su entorno de laboratorio Para este taller, usted trabajará de forma autónoma en su máquina virtual ya configurada y aislada. Su objetivo es producir un registro exhaustivo del estado actual de su instalación. Este registro servirá como base de referencia para todas las actividades futuras y es una práctica profesional indispensable.
