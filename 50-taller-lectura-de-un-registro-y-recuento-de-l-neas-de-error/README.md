# Taller: lectura de un registro y recuento de líneas de ERROR

**Recordatorio teórico** En Python, la lectura de archivos de texto se realiza con la función integrada open(). La sintaxis básica es: with open('archivo.txt', 'r') as f: — el uso del bloque with garantiza el cierre automático del archivo, incluso si ocurre un error. Una vez abierto, puedes leer el archivo línea por línea con un bucle for line in f:, lo que es eficiente en memoria y adecuado para archivos grandes como los registros (logs) de sistemas. Cada línea es una cadena de texto (str) que puede ser analizada con métodos como .strip() para eliminar espacios y saltos de línea, o 'ERROR' in line para verificar si contiene una cadena específica. Los registros de aplicaciones y servidores siguen generalmente un formato estructurado: [TIMESTAMP] NIVEL_SEVERIDAD mensaje. Los niveles de severidad más comunes son INFO, WARNING, ERROR y CRITICAL. En ciberseguridad, el análisis automatizado de logs es fundamental para detectar incidentes, intentos de intrusión o fallos de autenticación. Error frecuente: confundir el modo de apertura ('r' para lectura, 'w' para escritura). Intentar abrir un archivo inexistente sin manejo de excepciones provoca un FileNotFoundError que detiene el script. Mini-ejemplo: contador = 0 / for line in f: / if 'ERROR' in line: / contador += 1.
