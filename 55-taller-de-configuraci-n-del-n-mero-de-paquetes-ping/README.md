# Taller de : configuración del número de paquetes ping

**Recordatorio teórico** El módulo `subprocess` de Python permite lanzar comandos del sistema operativo directamente desde un script, capturar su salida y manejar errores de ejecución. El comando `ping` es una herramienta de diagnóstico de red que envía paquetes ICMP a un host para verificar su alcanzabilidad. En función del sistema operativo, el número de paquetes enviados se controla con opciones distintas: `-c` en Linux/macOS y `-n` en Windows. Ignorar esta diferencia es uno de los errores más frecuentes en principiantes, ya que el script funciona en un entorno pero falla silenciosamente en otro. Un error común es construir el comando ping con un número de paquetes fijo y codificado directamente en el código (lo que se llama 'hardcoding'), lo que elimina toda flexibilidad. Otro error habitual es no gestionar las excepciones cuando el comando falla o cuando el host no responde, lo que provoca que el script se interrumpa de forma inesperada. Mini-ejemplo conceptual: si se desea enviar 3 paquetes a '8.8.8.8', en Linux se ejecutaría `ping -c 3 8.8.8.8` y en Windows `ping -n 3 8.8.8.8`. En Python, esto se traduce en construir dinámicamente la lista de argumentos para `subprocess.run()` según el valor de `platform.system()`, permitiendo que el número de paquetes sea un parámetro configurable por el usuario o definido como variable al inicio del script. --- **Enunciado del taller** En el taller anterior, creaste un script Python que ejecutaba el comando `ping` sobre un host y guardaba la salida en un archivo.
