# Copie, mueva y elimine de forma segura

RECORDATORIO TEÓRICO Antes de comenzar el taller, repasa los conceptos esenciales que utilizarás. Los comandos cp, mv y rm son las tres herramientas fundamentales para manipular archivos en Linux. cp (copy) crea una copia de un archivo o directorio en una ubicación destino sin alterar el original; su opción -r permite copiar directorios de forma recursiva y -p preserva los permisos y marcas de tiempo, algo crítico en contextos de seguridad. mv (move) desplaza o renombra archivos y directorios: a diferencia de cp, el archivo original desaparece de su ubicación inicial. rm (remove) elimina archivos de forma permanente —no existe papelera de reciclaje en la terminal—; con -r elimina directorios recursivamente y con -f fuerza la eliminación sin confirmación. El error más frecuente y peligroso es ejecutar rm -rf sobre una ruta incorrecta, lo que puede destruir estructuras críticas del sistema de forma irreversible. Otro error habitual es copiar archivos sensibles a ubicaciones con permisos demasiado abiertos, creando brechas de seguridad. El modelo mental correcto es: antes de ejecutar cualquier comando destructivo, visualiza la ruta con ls o pwd, usa la opción -i (interactiva) para pedir confirmación, y trabaja siempre con rutas absolutas cuando el contexto sea crítico.
