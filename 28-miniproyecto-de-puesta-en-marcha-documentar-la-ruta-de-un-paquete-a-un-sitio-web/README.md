# Miniproyecto de puesta en marcha: documentar la ruta de un paquete a un sitio web

## Descripción del proyecto Este miniproyecto consiste en documentar de forma completa y rigurosa la ruta que sigue un paquete de red desde tu máquina local hasta un sitio web público. A través de esta experiencia práctica, movilizarás los conocimientos adquiridos sobre las capas del modelo OSI (capas 1 a 3), los protocolos de red (Ethernet, IP, TCP/UDP), el direccionamiento MAC e IP, y las herramientas de diagnóstico de red. El proyecto se inscribe directamente en el contexto profesional de la ciberseguridad: comprender cómo viajan los datos en la red es una competencia fundamental para cualquier especialista que desee realizar reconocimientos, analizar tráfico o identificar puntos de entrada potenciales en un sistema. ## Competencias validadas - Identificar y describir el papel de cada capa OSI implicada en la transmisión de un paquete (capas 1, 2 y 3). - Leer e interpretar una trama Ethernet (dirección MAC origen/destino, tipo de trama). - Analizar una cabecera IP (dirección IP origen/destino, TTL, protocolo). - Utilizar herramientas de diagnóstico de red: `traceroute` / `tracert`, `ping`, `Wireshark`. - Representar gráficamente la ruta de un paquete (topología de saltos). - Relacionar los conceptos técnicos con su relevancia en ciberseguridad (puntos de exposición, análisis de tráfico). ## Contexto pedagógico Este proyecto es la culminación de las actividades previas realizadas sobre el modelo OSI, las tramas Ethernet, el direccionamiento MAC, el rol de los enrutadores y el protocolo IP. Servirá como base para las actividades futuras centradas en capas superiores y en el análisis de vulnerabilidades de red.
