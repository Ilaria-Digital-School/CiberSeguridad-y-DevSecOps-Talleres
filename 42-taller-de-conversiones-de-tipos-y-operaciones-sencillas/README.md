# Taller de : conversiones de tipos y operaciones sencillas

**Recordatorio teórico** En Python, cada valor tiene un tipo de dato asociado: int (entero), float (decimal), str (cadena de texto) y bool (booleano). La conversión de tipos, también llamada casting, consiste en transformar un valor de un tipo a otro mediante funciones integradas como int(), float(), str() y bool(). Esta operación es frecuente en scripting de ciberseguridad: por ejemplo, al leer un puerto de red desde la entrada del usuario (que llega como str) y necesitar compararlo numéricamente. Error frecuente: intentar operar aritméticamente entre un str y un int sin convertir previamente. Por ejemplo, '8080' + 1 lanzará un TypeError. La solución es int('8080') + 1, que devuelve 8081. Otro error habitual es asumir que float('3.14') y int('3.14') se comportan igual: el segundo lanzará un ValueError porque un float en forma de cadena no puede convertirse directamente a int sin pasar primero por float. Modelo mental clave: piensa en los tipos como contenedores de diferente forma. Antes de operar entre dos valores, verifica que sus contenedores sean compatibles o conviértelos explícitamente. Las operaciones básicas en Python incluyen suma (+), resta (-), multiplicación (*), división (/), división entera (//), módulo (%) y potencia (**). Comprender el módulo es especialmente útil en ciberseguridad para calcular rangos, máscaras o verificar paridades.
