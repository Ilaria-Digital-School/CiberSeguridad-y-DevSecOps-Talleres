# Aplique una lista de verificación de endurecimiento en VM labo

## Contexto del proyecto En un contexto DevSecOps, cada servidor Linux desplegado debe cumplir un nivel mínimo de seguridad antes de entrar en producción. Los referentes CIS (Center for Internet Security) proporcionan listas de verificación de endurecimiento (hardening) reconocidas en la industria. Tu misión consiste en aplicar, documentar y verificar una lista de verificación de endurecimiento sobre una máquina virtual de laboratorio Linux (Ubuntu Server o Debian), consolidando así todas las competencias adquiridas en este capítulo: gestión de usuarios y sudoers, permisos, scripts automatizados, cron, registros/auditoría y principios de minimización CIS. ## Descripción Partirás de una VM Linux recién instalada (estado 'base'). Realizarás un diagnóstico inicial, aplicarás progresivamente medidas de endurecimiento derivadas del referente CIS, automatizarás una parte del proceso mediante un script bash, y verificarás/documentarás los resultados obtenidos. El proyecto simula la tarea real de un ingeniero de seguridad que prepara un servidor conforme antes del despliegue. ## Ámbito de endurecimiento a cubrir 1. **Cuentas y autenticación** : política de contraseñas, expiración, bloqueo de cuentas inactivas, desactivación de root por SSH, verificación de sudoers. 2. **Servicios y minimización** : identificación y desactivación de servicios/paquetes innecesarios, cierre de puertos abiertos no justificados. 3. **Sistema de archivos y permisos** : verificación de permisos sensibles (/etc/passwd, /etc/shadow, ficheros SUID/SGID), montaje de particiones con opciones seguras (noexec, nosuid). 4. **Endurecimiento SSH** : desactivación de root login, PermitEmptyPasswords, autenticación por clave, protocolo y ciphers. 5. **Registro y auditoría** : configuración de journald/rsyslog, logrotate, activación de auditd para eventos críticos, análisis de auth.log. 6. **Cortafuegos**...
