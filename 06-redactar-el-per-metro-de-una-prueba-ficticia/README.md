# Redactar el perímetro de una prueba ficticia

Recordatorio teórico: Fundamentos del perímetro de prueba Un perímetro de prueba de intrusión, o Scope of Work, es un documento contractual esencial que delimita los límites precisos, objetivos y reglas de una evaluación de seguridad autorizada. Define qué sistemas, aplicaciones o redes pueden ser probados, a través de qué métodos y en qué momento. Su propósito es crear un marco legal y operativo seguro para el cliente y el evaluador, asegurando que las actividades de prueba no causen interrupciones comerciales no deseadas o afecten sistemas fuera del acuerdo. El modelo mental clave es el de una "caja blanca" con reglas claras: usted debe saber exactamente dónde termina el área autorizada para operar. Los errores frecuentes incluyen definir objetivos de manera demasiado vaga utilizando términos como "toda la red", omitir una sección robusta de "fuera del perímetro" para excluir sistemas críticos, o no definir reglas de compromiso sobre métodos prohibidos, por ejemplo, ataques de denegación de servicio. Un mini-ejemplo para una empresa ficticia 'TechCorp' podría ser: Perímetro interior: el servidor web www.techcorp-example.com (IP 192.0.2.10) y la aplicación de cliente en app.techcorp-example.com. Fuera del perímetro: los servidores de correo electrónico y el sistema ERP interno. Reglas: pruebas permitidas de lunes a viernes, de 19:00 a 01:00, sin ataques volumétricos. Esta precisión evita ambigüedades peligrosas.
