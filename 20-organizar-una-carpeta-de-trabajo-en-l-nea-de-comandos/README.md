# Organizar una carpeta de trabajo en línea de comandos

Recordatorio teórico Una organización metódica de archivos y directorios es fundamental para cualquier profesional de ciberseguridad que trabaje en línea de comandos. En Linux, todo parte del sistema de archivos jerárquico, donde la raíz (/) es el punto de partida. Los comandos como `mkdir`, `cp`, `mv`, `rm` y `rmdir` son herramientas esenciales para crear, copiar, mover y eliminar elementos. La ruta absoluta especifica la ubicación completa desde la raíz, mientras que la ruta relativa se define en relación con el directorio de trabajo actual, obtenido con `pwd`. Un modelo mental útil es imaginar el sistema de archivos como un árbol invertido. Cada directorio puede contener archivos y otros directorios (subdirectorios). La navegación se realiza con `cd`, y la creación de estructuras complejas puede simplificarse usando opciones como `mkdir -p` para crear múltiples niveles de directorios de una sola vez. Un error frecuente es no verificar el directorio de trabajo antes de operar, lo que lleva a crear estructuras en lugares incorrectos. Otro es usar `rm -r` sin precaución, eliminando irreversiblemente datos no deseados. Mini-ejemplo: Para crear un directorio llamado `investigacion` dentro de `~/proyectos/2024` y un subdirectorio `evidencias` dentro de él, se usaría `mkdir -p ~/proyectos/2024/investigacion/evidencias`. Esto ilustra cómo una sola orden construye una jerarquía completa. Para documentar una estructura, el comando `tree` proporciona una vista esquemática clara. Las herramientas de línea de comandos, combinadas con una planificación previa, permiten construir entornos de trabajo organizados, repetibles y profesionales.
