# Explorar el entorno de su máquina virtual Linux

Recordatorio teórico: Fundamentos del sistema operativo Linux Un sistema operativo es el software principal que gestiona los recursos de hardware y proporciona servicios comunes a los programas de aplicación. Actúa como intermediario entre el usuario y el hardware físico. En el modelo mental de Linux, todo es un archivo o un proceso, y la jerarquía sigue una estructura de directorios unificada que comienza desde la raíz (/). Linux es un sistema operativo de código abierto basado en el núcleo (kernel) Linux. Una distribución (distro) es una versión completa de Linux que incluye el kernel, herramientas del sistema, software adicional y un gestor de paquetes. Ejemplos de distribuciones populares incluyen Ubuntu, Debian y Fedora. Un usuario se autentica con un nombre de usuario y una contraseña, y opera dentro de los límites de permisos asignados a su cuenta. Los errores frecuentes incluyen confundir comandos similares (como `ls` para listar y `ls -l` para detalles), no comprender la sintaxis de las rutas absolutas (comenzando con /) y relativas, y olvidar que Linux diferencia entre mayúsculas y minúsculas en nombres de archivos y comandos. Mini-ejemplo: Si una máquina tiene 4 GB de RAM física y 2 GB de espacio de intercambio (swap), el espacio de memoria total utilizable es de 6 GB. El comando `free -h` mostraría algo como: Mem: 3.9G total, 2.1G usada, 1.8G libre; Swap: 2.0G total, 0G usada, 2.0G libre.
