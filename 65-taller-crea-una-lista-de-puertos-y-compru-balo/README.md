# Taller: crea una lista de puertos y compruébalo

RECORDATORIO TEÓRICO En Python, las estructuras de datos como listas y diccionarios son fundamentales para organizar información de manera eficiente. Una lista es una colección ordenada y mutable de elementos: por ejemplo, puertos = [22, 80, 443, 8080]. Un diccionario asocia claves a valores: servicios = {22: 'SSH', 80: 'HTTP', 443: 'HTTPS'}. En el contexto de la ciberseguridad, estas estructuras permiten gestionar conjuntos de puertos, rangos de IPs o resultados de escaneos de forma sistemática. Un error frecuente entre principiantes es confundir la iteración sobre una lista con la iteración sobre un diccionario: al recorrer un diccionario con 'for k in d', se obtienen las claves, no los valores. Para acceder a ambos, se utiliza 'd.items()'. Otro error habitual es intentar verificar la conectividad de un puerto directamente con 'ping': el comando ping verifica disponibilidad ICMP, no el estado de un puerto TCP/UDP específico. Para comprobar si un puerto está abierto, se utiliza el módulo 'socket' de Python. Mini-ejemplo: import socket puertos = [22, 80, 443] for puerto in puertos: s = socket.socket() s.settimeout(1) resultado = s.connect_ex(('127.0.0.1', puerto)) print(f'Puerto {puerto}: {"abierto" if resultado == 0 else "cerrado"}') s.close() Este patrón es la base del taller.
