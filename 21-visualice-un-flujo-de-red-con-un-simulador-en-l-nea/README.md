# Visualice un flujo de red con un simulador en línea

RECORDATORIO TEÓRICO Antes de comenzar este taller, repase los conceptos fundamentales vistos en las actividades anteriores. Una red es un conjunto de hosts (computadoras, servidores, dispositivos) interconectados mediante enlaces físicos o inalámbricos. La comunicación entre ellos se realiza a través de paquetes: bloques de datos que contienen una cabecera (con la dirección IP de origen y destino) y una carga útil (los datos reales). Cada dispositivo en una red posee una dirección IP única que permite identificarlo y enrutar los paquetes correctamente. La topología de red describe cómo están organizados los dispositivos: en estrella, malla, bus, etc. Los conmutadores (switches) operan en la capa de enlace de datos y conectan dispositivos dentro de una misma red local, mientras que los routers operan en la capa de red y conectan redes distintas, tomando decisiones de enrutamiento basadas en direcciones IP. Un error frecuente en este nivel es confundir el rol del switch con el del router: el switch no interpreta direcciones IP, sino direcciones MAC; es el router quien decide hacia dónde reenviar un paquete fuera de la red local. Otro error común es pensar que un paquete viaja directamente del origen al destino: en realidad, puede pasar por múltiples routers intermedios (saltos o hops). Ejemplo mental: cuando escribe una URL en su navegador, su computadora genera paquetes con su IP de origen y la IP del servidor de destino. Esos paquetes salen por el router de su red doméstica y viajan hop a hop hasta el servidor remoto. --- ENUNCIADO...
