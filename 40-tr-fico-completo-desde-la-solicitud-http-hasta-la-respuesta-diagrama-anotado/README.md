# Tráfico completo: desde la solicitud HTTP hasta la respuesta (diagrama anotado)

## Descripción del proyecto Este mini-proyecto tiene como objetivo consolidar y demostrar la comprensión integral del ciclo de vida de una comunicación HTTP, desde que el usuario introduce una URL en su navegador hasta que recibe la respuesta del servidor. El estudiante deberá producir un **diagrama anotado y detallado** que cubra todas las capas del modelo OSI implicadas, los protocolos involucrados (DNS, TCP, HTTP, NAT, etc.) y los mecanismos de red subyacentes. Este proyecto integrador es la culminación del capítulo 'Fundamentos de las redes, protocolos y modelos OSI' y moviliza todos los conocimientos adquiridos en las actividades previas: subredes, NAT, DNS, TCP/UDP, HTTP y análisis con Wireshark. ## Contexto profesional En el ámbito de la ciberseguridad y el DevSecOps, comprender con precisión el flujo de una solicitud HTTP es fundamental para: - Identificar puntos de interceptación y vectores de ataque (Man-in-the-Middle, DNS spoofing, session hijacking, etc.). - Analizar capturas de tráfico durante un pentest. - Configurar correctamente herramientas de análisis y defensa (Wireshark, iptables, proxies). - Detectar anomalías o comportamientos maliciosos en el tráfico de red. ## Compétencias a validar 1. Describir el rol de cada capa OSI (4 a 7) en una comunicación HTTP. 2. Explicar el proceso completo de resolución DNS previo a la conexión. 3. Detallar el establecimiento de la conexión TCP (three-way handshake). 4. Explicar el rol de NAT en el tráfico saliente y entrante. 5. Identificar los componentes de una solicitud y respuesta HTTP. 6.
