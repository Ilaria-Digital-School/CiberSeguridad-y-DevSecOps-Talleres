# Taller: recorre una secuencia de puertos con for

**Recordatorio teórico: el bucle for en Python** El bucle `for` es una estructura de control que permite iterar sobre una secuencia de elementos de forma ordenada y predecible. A diferencia del bucle `while`, que depende de una condición booleana, el `for` recorre directamente los elementos de un iterable: una lista, una cadena de texto, o —lo más frecuente en automatización— un rango numérico generado por `range()`. La función `range(inicio, fin, paso)` genera una secuencia de enteros desde `inicio` hasta `fin - 1`, con un incremento definido por `paso`. Por ejemplo, `range(1, 1025)` genera todos los enteros del 1 al 1024, lo que resulta directamente útil para recorrer el rango de puertos reservados del sistema. Un error frecuente en principiantes es confundir el límite superior de `range()`: recuerda que el valor final es **excluido**. Si quieres incluir el puerto 1024, debes escribir `range(1, 1025)`. Otro error habitual es olvidar que la variable de iteración (por ejemplo, `puerto`) toma un nuevo valor en cada vuelta del bucle de forma automática; no necesitas incrementarla manualmente. Mini-ejemplo orientativo: ```python for puerto in range(20, 26): print(f"Analizando puerto: {puerto}") ``` Este fragmento imprime los puertos del 20 al 25 inclusive.
