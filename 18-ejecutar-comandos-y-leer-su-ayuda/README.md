# Ejecutar comandos y leer su ayuda

Recordatorio teórico Un sistema operativo como Linux se gestiona mediante comandos de texto en el terminal. Un comando es una instrucción que el usuario escribe para realizar una operación concreta en el sistema. Cada comando suele seguir una estructura básica: el nombre del programa, seguido de opciones (modificadores que empiezan por uno o dos guiones) y argumentos (datos o objetivos sobre los que actúa). Un modelo mental útil es imaginar que cada comando es una herramienta especializada con un manual de instrucciones incorporado. Los errores más frecuentes incluyen: olvidar los espacios entre elementos, confundir guiones simples y dobles, escribir mal el nombre del comando o no comprender qué argumentos son obligatorios. Otro error común es no consultar la ayuda antes de utilizar un comando nuevo, lo que lleva a resultados inesperados. Por ejemplo, para listar los archivos de un directorio con detalles, el comando `ls -l /home` se desglosa así: `ls` es el nombre del programa (listar), `-l` es una opción (formato largo), y `/home` es un argumento (el directorio objetivo). La mayoría de comandos permiten verificar esta sintaxis mediante sus sistemas de ayuda integrados.
