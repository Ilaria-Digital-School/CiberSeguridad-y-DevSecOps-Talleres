# Taller: compruebe la presencia de X-Frame-Options

**Recordatorio teórico** El encabezado HTTP X-Frame-Options es una medida de seguridad que indica al navegador si una página web puede ser incrustada dentro de un elemento , o en otro dominio. Su ausencia expone la aplicación a ataques de tipo Clickjacking, donde un atacante superpone una página invisible sobre otra para engañar al usuario y hacerle ejecutar acciones no deseadas (clics fraudulentos, transferencias bancarias, cambios de configuración, etc.). Existen tres valores posibles para este encabezado: DENY (la página nunca puede ser incrustada), SAMEORIGIN (solo puede ser incrustada por páginas del mismo dominio) y ALLOW-FROM uri (permite la incrustación desde un origen específico, aunque este valor está obsoleto en navegadores modernos y debe evitarse). Un error frecuente de los principiantes es confundir la ausencia del encabezado con un valor explícito de permiso; en realidad, si el encabezado no aparece en la respuesta HTTP, el comportamiento del navegador es permisivo por defecto, lo que equivale a una vulnerabilidad. En el capítulo anterior trabajaste con la biblioteca requests de Python para analizar encabezados HTTP. Aquí aplicarás ese conocimiento de forma directa: realizarás una petición GET a una URL objetivo y examinarás el diccionario de encabezados de la respuesta para comprobar si X-Frame-Options está presente, cuál es su valor y si ese valor es adecuado desde el punto de vista de la seguridad. Mini-ejemplo conceptual: si ejecutas response = requests.get('https://ejemplo.com') y luego imprimes response.headers, obtendrás un diccionario con todos los encabezados devueltos por el servidor.
