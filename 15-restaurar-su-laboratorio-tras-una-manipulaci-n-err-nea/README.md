# Restaurar su laboratorio tras una manipulación errónea

Recordatorio teórico En el entorno de un laboratorio aislado para ciberseguridad, una manipulación errónea es cualquier acción que compromete la configuración base operativa o la integridad de los objetivos de entrenamiento. El modelo mental clave es el "estado conocido y bueno", una instantánea del sistema donde todas las herramientas funcionan y los objetivos son accesibles como se diseñaron inicialmente. Los errores frecuentes incluyen la eliminación accidental de archivos críticos del sistema, la modificación de configuraciones de red que rompen el aislamiento, la instalación de paquetes de software conflictivos o la corrupción de una máquina virtual base. Un mini-ejemplo sería eliminar, por error, la interfaz de red principal de su máquina virtual Kali Linux utilizando un comando como `ip link delete eth0`, resultando en la pérdida completa de conectividad dentro del laboratorio aislado. La restauración efectiva no es sobre deshacer cada cambio individual, sino sobre volver sistemáticamente a un punto de partida verificado. Este proceso depende fundamentalmente del uso de instantáneas o snapshots de su software de virtualización, como VMware Workstation, VirtualBox o Hyper-V. Estas instantáneas capturan el estado exacto de disco y memoria de una máquina virtual en un momento dado, permitiendo revertir a él. Configuración inicial y creación del error Antes de empezar, asegúrese de que su laboratorio está en el estado "completo y aislado" que usted mismo verificó en actividades anteriores.
