# Taller: función est_pair (port)

**Recordatorio teórico** Una función en Python es un bloque de código reutilizable que realiza una tarea específica. Se define con la palabra clave `def`, seguida del nombre de la función y sus parámetros entre paréntesis. La función puede devolver un valor usando `return`. Por ejemplo: `def saludar(nombre): return 'Hola ' + nombre`. Un concepto fundamental ligado a las funciones es el uso de condiciones (`if/else`) para tomar decisiones dentro del código. En el contexto de la ciberseguridad y el escaneo de puertos, es muy habitual necesitar clasificar puertos según criterios específicos: por ejemplo, determinar si un número de puerto es par o impar. Esta distinción puede ser relevante para filtrar o priorizar puertos durante una fase de reconocimiento. Para saber si un número es par, se utiliza el operador módulo `%`, que devuelve el resto de una división entera: si `port % 2 == 0`, el puerto es par; en caso contrario, es impar. Error frecuente: confundir `=` (asignación) con `==` (comparación). Otro error habitual es olvidar el `return`, haciendo que la función devuelva `None` en lugar del resultado esperado. Mini-ejemplo: `def es_par(n): return n % 2 == 0` → `es_par(80)` devuelve `True`, `es_par(443)` devuelve `False`.
