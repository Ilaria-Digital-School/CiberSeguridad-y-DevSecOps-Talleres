# Escanear puertos con Nmap (nivel principiante)

**Recordatorio teórico** Antes de lanzarte al taller, repasa estos conceptos clave. Un puerto es un número lógico (del 0 al 65535) que permite a un sistema operativo distinguir los diferentes servicios en ejecución sobre una misma dirección IP. El protocolo TCP utiliza un proceso de handshake en tres pasos (SYN / SYN-ACK / ACK) para establecer conexiones confiables, mientras que UDP no establece conexión previa. Los puertos bien conocidos (0-1023) corresponden a servicios estándar: 80 (HTTP), 443 (HTTPS), 53 (DNS), 22 (SSH), 21 (FTP). Un escáner de puertos como Nmap sondea estos puertos para determinar si están abiertos, cerrados o filtrados por un firewall. Modelo mental: imagina que llegas a un edificio y llamas a cada puerta. Si alguien responde, la puerta está 'abierta' (un servicio escucha). Si nadie responde pero la puerta existe, está 'cerrada'. Si un portero te impide acercarte, el puerto está 'filtrado'. Errores frecuentes: confundir IP pública e IP privada al interpretar resultados; olvidar que escanear sin autorización es ilegal; creer que todos los puertos abiertos son vulnerabilidades (un puerto abierto simplemente indica un servicio activo). Mini-ejemplo: `nmap 127.0.0.1` escanea tu propia máquina local y te mostrará qué servicios tienes activos en este momento. --- **Enunciado del taller** Este taller tiene como objetivo familiarizarte con Nmap, una de las herramientas más utilizadas en ciberseguridad para el reconocimiento de redes.
