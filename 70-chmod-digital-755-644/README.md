# Chmod digital 755/644

**Recordatorio teórico** En Linux, cada archivo y directorio tiene asociados tres conjuntos de permisos: propietario (user), grupo (group) y otros (others). Cada conjunto puede combinar tres tipos de acceso: lectura (r = 4), escritura (w = 2) y ejecución (x = 1). La notación octal suma estos valores para expresar los permisos en un solo dígito por conjunto. Así, 7 = rwx (4+2+1), 5 = r-x (4+0+1) y 4 = r-- (4+0+0). Los dos valores más utilizados en entornos de producción son 755 y 644. El modo 755 (rwxr-xr-x) es habitual en directorios y scripts ejecutables: el propietario puede leer, escribir y ejecutar; el grupo y otros solo pueden leer y ejecutar. El modo 644 (rw-r--r--) es el estándar para archivos de datos y configuración: el propietario puede leer y escribir; el grupo y otros solo pueden leer. Error frecuente: aplicar 777 (rwxrwxrwx) a archivos de configuración 'para que todo funcione', lo que expone credenciales y permite modificaciones maliciosas. Otro error clásico es confundir permisos de directorio y de archivo: un directorio necesita el bit de ejecución para poder ser atravesado (cd), aunque no contenga scripts. Mini-ejemplo mental: un archivo de contraseñas como /etc/shadow tiene permisos 640 o incluso 000, porque solo el sistema debe leerlo. Un script de despliegue tendrá 750 si solo el propietario y el grupo deben ejecutarlo. --- **Enunciado del taller** Este taller tiene como objetivo consolidar tu comprensión de la notación octal de chmod y su aplicación práctica en un contexto de seguridad real.
