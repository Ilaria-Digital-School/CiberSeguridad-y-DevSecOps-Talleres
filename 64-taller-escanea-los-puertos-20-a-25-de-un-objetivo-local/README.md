# Taller: escanea los puertos 20 a 25 de un objetivo local

**Recordatorio teórico** Un socket es un punto de comunicación entre dos máquinas a través de una red. En Python, el módulo `socket` permite crear conexiones TCP/UDP de manera programática. Para escanear un puerto, se intenta establecer una conexión TCP con `socket.connect_ex(host, puerto)`: si la función devuelve 0, el puerto está abierto; cualquier otro valor indica que está cerrado o filtrado. Es importante entender que este método realiza un 'TCP Connect Scan', el tipo de escaneo más simple pero también el más detectable por un sistema de seguridad. Un error frecuente de los principiantes es olvidar configurar un tiempo de espera (`socket.setdefaulttimeout(1)`) antes de intentar la conexión: sin este parámetro, el script puede bloquearse durante decenas de segundos por puerto si el host no responde. Otro error habitual es no cerrar el socket después de cada intento, lo que provoca fugas de recursos. Finalmente, confundir el rango de puertos es común: `range(20, 26)` en Python genera los valores 20, 21, 22, 23, 24 y 25, es decir, los seis puertos objetivo. Mini-ejemplo conceptual: ```python import socket s = socket.socket() s.settimeout(1) resultado = s.connect_ex(('127.0.0.1', 22)) if resultado == 0: print('Puerto 22 abierto') s.close() ``` Este fragmento ilustra la lógica central que deberás extender para cubrir el rango completo de puertos. --- **Enunciado del taller** En este taller pondrás en práctica los conocimientos adquiridos sobre sockets en Python para desarrollar un escáner de puertos funcional orientado a un objetivo local.
