# Taller: declaración de variables y visualización de sus tipos

**Recordatorio teórico** En Python, una variable es un nombre simbólico que apunta a un valor almacenado en memoria. A diferencia de lenguajes como C o Java, Python es de tipado dinámico: no es necesario declarar explícitamente el tipo de una variable antes de usarla. El intérprete infiere el tipo en tiempo de ejecución según el valor asignado. Los tipos básicos más utilizados son: int (enteros, ej. 42), float (decimales, ej. 3.14), str (cadenas de texto, ej. 'admin'), bool (booleanos: True o False) y NoneType (valor nulo: None). Para conocer el tipo de cualquier variable, se utiliza la función integrada type(). Un error frecuente entre principiantes es confundir una cadena de texto que contiene un número ('8080') con un entero real (8080): son tipos distintos y no se comportan igual en operaciones matemáticas ni en comparaciones. Otro error habitual es sobreescribir sin querer una variable al reutilizar el mismo nombre con un tipo diferente, lo que puede generar bugs difíciles de rastrear. Mini-ejemplo: puerto = 8080 → type(puerto) devuelve int; servicio = 'ssh' → type(servicio) devuelve str; activo = True → type(activo) devuelve bool. Comprender estos fundamentos es esencial en ciberseguridad, donde los scripts Python manipulan constantemente puertos, direcciones IP, credenciales y flags de estado. --- **Enunciado del taller** Este taller tiene como objetivo consolidar tu comprensión práctica de la declaración de variables en Python y la visualización de sus tipos en el contexto de scripts orientados a la seguridad informática.
