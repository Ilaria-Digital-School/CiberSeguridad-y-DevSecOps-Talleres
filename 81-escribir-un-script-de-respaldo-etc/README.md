# Escribir un script de respaldo /etc

RECORDATORIO TEÓRICO El directorio /etc contiene la mayor parte de los archivos de configuración de un sistema Linux: usuarios (/etc/passwd, /etc/shadow), red (/etc/hosts, /etc/resolv.conf), servicios (SSH, firewall, cron) y muchos otros. Perder o corromper /etc puede dejar una máquina inoperante o insegura, por eso respaldarlo con regularidad es una práctica fundamental en administración y ciberseguridad. Un script de respaldo es simplemente un programa Bash que automatiza tareas repetitivas. El modelo mental que debes tener es sencillo: un buen script debe ser idempotente (se puede ejecutar varias veces sin efectos indeseados), robusto (gestiona los errores) y trazable (deja un registro de lo ocurrido). En este taller reutilizarás los conceptos vistos en «Secuencias de comandos de Bash: variables, bucles, condiciones». La herramienta clave será tar, que permite crear un archivo comprimido: por ejemplo, tar -czf backup.tar.gz /etc empaqueta y comprime todo el directorio. Para diferenciar cada copia se añade una marca de tiempo con el comando date, por ejemplo etc-$(date +%Y%m%d-%H%M%S).tar.gz. Errores frecuentes: olvidar los permisos de root para leer /etc/shadow, no verificar si el directorio de destino existe, no controlar el código de retorno de los comandos, y guardar los respaldos en el mismo disco que se quiere proteger. Un mini-ejemplo básico sería: #!/bin/bash DESTINO="/var/backups" ARCHIVO="etc-$(date +%Y%m%d).tar.gz" tar -czf "$DESTINO/$ARCHIVO" /etc A partir de esta base construirás un script mucho más completo y profesional. --- ENUNCIADO DEL WORKSHOP Tu objetivo es diseñar un script Bash llamado backup_etc.sh que realice una copia de seguridad comprimida del directorio /etc de forma automática, segura...
