# Miniproyecto final: script de auditoría básico (ping, nmap, encabezados) con informe

## Descripción del proyecto Este miniproyecto final tiene como objetivo consolidar todas las competencias adquiridas a lo largo del capítulo 'Conceptos básicos de programación en Python para la automatización de la seguridad'. El estudiante deberá desarrollar un script de auditoría completo en Python que integre tres módulos funcionales: verificación de disponibilidad de hosts mediante ping, escaneo de puertos con Nmap y análisis de encabezados HTTP. El resultado final será un informe de auditoría generado automáticamente en múltiples formatos. Este proyecto simula un escenario real de reconocimiento inicial en un entorno de pruebas autorizado, tal como lo realizaría un especialista en ciberseguridad o DevSecOps durante la fase de reconocimiento de un pentest. ## Contexto profesional En el marco de una misión de auditoría de seguridad, se te encarga automatizar la fase de reconocimiento técnico de un perímetro autorizado. El cliente necesita un informe estructurado que recoja: el estado de disponibilidad de los hosts, los puertos abiertos detectados y el análisis de las cabeceras de seguridad HTTP presentes o ausentes en sus servicios web. Tu script debe ser reutilizable, seguro y bien documentado. ## Competencias validadas - Escritura de scripts Python modulares y seguros - Uso de subprocesos para ejecutar comandos del sistema (ping, nmap) - Integración de la biblioteca `requests` para análisis HTTP - Manipulación y formateo de fechas y marcas de tiempo - Generación de informes en múltiples formatos (texto, CSV, JSON) - Aplicación de buenas prácticas de scripting seguro (gestión de permisos, secretos, rutas) - Captura y análisis de...
