# Asocie las direcciones IP con el equipo

RECORDATORIO TEÓRICO Una dirección IP (Internet Protocol) es un identificador numérico único asignado a cada dispositivo conectado a una red. Existen dos versiones en uso: IPv4 (formato XXX.XXX.XXX.XXX, por ejemplo 192.168.1.10) e IPv6 (formato hexadecimal más largo). En una red local, cada equipo —ordenador, impresora, router, smartphone— posee al menos una dirección IP que permite identificarlo y comunicarse con él mediante el envío de paquetes. El modelo mental clave es el siguiente: piense en la dirección IP como el número de apartamento de un edificio. El edificio es la red, y cada apartamento (dispositivo) tiene un número único dentro de ese edificio. El router actúa como el portero que distribuye y redirige los paquetes hacia el apartamento correcto. Errores frecuentes: confundir la dirección IP con la dirección MAC (que es un identificador físico de la tarjeta de red, no lógico), creer que la dirección IP siempre es fija (puede ser dinámica, asignada por DHCP), o ignorar que un mismo equipo puede tener varias interfaces de red, cada una con su propia IP. Mini-ejemplo: si ejecuta el comando 'ip a' (Linux/Mac) o 'ipconfig' (Windows) en su máquina, verá algo como: inet 192.168.1.42/24. Esto significa que su equipo tiene la IP 192.168.1.42 dentro de la red 192.168.1.0/24. --- ENUNCIADO DEL TALLER En este taller pondrá en práctica los conceptos aprendidos sobre direcciones IP y vocabulario de red.
