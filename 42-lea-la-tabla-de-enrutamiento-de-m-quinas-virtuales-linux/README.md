# Lea la tabla de enrutamiento de máquinas virtuales Linux

**Recordatorio teórico** Una tabla de enrutamiento es una estructura de datos almacenada en el kernel del sistema operativo que determina cómo se reenvían los paquetes IP de una interfaz de red a otra. Cada entrada de la tabla contiene, como mínimo: la red de destino (en notación CIDR), la puerta de enlace (gateway) a través de la cual se alcanza ese destino, la interfaz de red utilizada, y una métrica que indica la 'preferencia' de esa ruta. La ruta por defecto (0.0.0.0/0 o ::/0 en IPv6) es la que se usa cuando ninguna otra entrada coincide con el destino del paquete: es la 'salida al mundo exterior'. Un error frecuente en los principiantes es confundir la dirección de la puerta de enlace con la dirección de destino de la red. La puerta de enlace es el próximo salto (next hop), es decir, el router al que se envía el paquete, no el destino final. Otro error habitual es ignorar la columna de flags: la flag 'U' indica que la ruta está activa (Up), mientras que 'G' indica que se utiliza un gateway. Si no aparece 'G', el destino es directamente accesible en la red local.
