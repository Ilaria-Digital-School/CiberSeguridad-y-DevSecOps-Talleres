# Lea una trama Ethernet capturada

**Recordatorio teórico** Una trama Ethernet es la unidad de datos que circula en la capa 2 (Enlace de datos) del modelo OSI. Está compuesta por campos bien definidos: la dirección MAC de destino (6 bytes), la dirección MAC de origen (6 bytes), el campo EtherType o longitud (2 bytes, que indica el protocolo de capa superior encapsulado, por ejemplo 0x0800 para IPv4 o 0x0806 para ARP), los datos (payload, entre 46 y 1500 bytes) y el FCS o Frame Check Sequence (4 bytes de control de errores al final). Las direcciones MAC son identificadores únicos de 48 bits asignados a cada interfaz de red, habitualmente expresados en hexadecimal (por ejemplo, AA:BB:CC:DD:EE:FF). Los tres primeros bytes identifican al fabricante (OUI, Organizationally Unique Identifier). Error frecuente: confundir la dirección MAC con la dirección IP. La MAC opera en capa 2 y es local al segmento de red; la IP opera en capa 3 y permite el enrutamiento entre redes. Otro error habitual es leer el campo EtherType como longitud sin verificar su valor: si es mayor que 1500 (0x05DC), se trata de un identificador de protocolo. Ejemplo mental: cuando tu ordenador envía un ping, construye un paquete IP (capa 3) que se encapsula en una trama Ethernet (capa 2).
