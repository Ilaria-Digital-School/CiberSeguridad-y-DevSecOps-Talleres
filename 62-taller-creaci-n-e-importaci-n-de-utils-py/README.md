# Taller: creación e importación de utils.py

RECORDATORIO TEÓRICO En Python, un módulo es simplemente un archivo .py que contiene funciones, variables o clases que se pueden reutilizar en otros scripts. El archivo utils.py (abreviatura de 'utilities') es una convención ampliamente utilizada en proyectos profesionales para agrupar funciones de utilidad genéricas que se emplean en múltiples partes de un programa. En lugar de copiar y pegar el mismo código en varios scripts, se centraliza la lógica reutilizable en un único archivo y se importa donde sea necesario. Para importar un módulo propio, el archivo utils.py debe encontrarse en el mismo directorio que el script principal (o en el PYTHONPATH). Se puede importar de tres formas: 'import utils' (acceso con utils.nombre_funcion()), 'from utils import nombre_funcion' (acceso directo) o 'from utils import *' (importa todo, pero se desaconseja en proyectos grandes por problemas de legibilidad y conflictos de nombres). Errores frecuentes: olvidar que utils.py debe estar en el mismo directorio que el script que lo importa; confundir el nombre del módulo con el nombre del archivo (sin la extensión .py); intentar importar una función que no existe o está mal escrita (ModuleNotFoundError o ImportError). Un mini-ejemplo: si utils.py contiene 'def saludar(): return "Hola"', entonces en main.py escribimos 'from utils import saludar' y luego 'print(saludar())' para obtener 'Hola'. Este patrón es fundamental en ciberseguridad y DevSecOps: los scripts de automatización de seguridad (análisis de logs, parseo de resultados de Nmap, generación de informes) comparten funciones comunes que conviene centralizar en un utils.py para mantener el código limpio, mantenible y reutilizable....
