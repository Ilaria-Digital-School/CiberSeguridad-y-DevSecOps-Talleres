# Taller: extracción de todas las direcciones IP de un registro

RECORDATORIO TEÓRICO Las expresiones regulares (regex) son patrones de búsqueda que permiten localizar, extraer o manipular cadenas de texto de forma precisa y eficiente. En Python, el módulo `re` proporciona todas las herramientas necesarias para trabajar con regex. Las funciones más utilizadas son: `re.findall()`, que devuelve una lista con todas las coincidencias encontradas en un texto; `re.search()`, que localiza la primera coincidencia; y `re.match()`, que verifica si el patrón coincide al inicio de la cadena. Una dirección IPv4 sigue el formato `X.X.X.X`, donde cada `X` es un número entre 0 y 255. El patrón regex más común para capturarlas es: `\b(?:\d{1,3}\.){3}\d{1,3}\b`. Este patrón usa `\d{1,3}` para uno a tres dígitos, `\.` para el punto literal, y `\b` para delimitar la palabra. Un error frecuente es olvidar escapar el punto (usar `.` en lugar de `\.`), lo que haría que el patrón coincida con cualquier carácter en lugar del punto literal. Otro error habitual es usar `re.search()` cuando se necesita extraer múltiples resultados: en ese caso, la función correcta es `re.findall()`. Mini-ejemplo: dado el texto `'Conexión de 192.168.1.1 a 10.0.0.5'`, la llamada `re.findall(r'\b(?:\d{1,3}\.){3}\d{1,3}\b', texto)` devolvería `['192.168.1.1', '10.0.0.5']`.
