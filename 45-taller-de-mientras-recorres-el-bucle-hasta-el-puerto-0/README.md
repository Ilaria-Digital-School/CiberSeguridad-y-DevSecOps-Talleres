# Taller de : mientras recorres el bucle hasta el puerto 0

**Recordatorio teórico** En Python, el bucle `while` (mientras) permite repetir un bloque de instrucciones mientras una condición sea verdadera. A diferencia del bucle `for`, que itera sobre una secuencia conocida de antemano, el `while` es ideal cuando el número de iteraciones depende de una condición dinámica que puede cambiar en cada vuelta. Su estructura básica es: `while condicion:` seguido del bloque indentado de instrucciones. Es fundamental actualizar la variable de control dentro del bucle; de lo contrario, se entra en un bucle infinito, uno de los errores más frecuentes en principiantes. Por ejemplo, si quieres decrementar un contador de puerto: `puerto = 1024` / `while puerto > 0:` / ` print(puerto)` / ` puerto -= 1`. Este código imprimirá todos los números desde 1024 hasta 1, deteniéndose automáticamente cuando `puerto` llega a 0. Un error habitual es olvidar el `puerto -= 1`, lo que hace que el programa nunca termine. Otro error común es confundir la condición de parada: usar `>` en lugar de `>=` puede hacer que se omita o incluya el valor límite. Recuerda también que `while True:` combinado con `break` es un patrón válido para salidas controladas dentro del bucle. **Enunciado del taller** En el ámbito de la ciberseguridad, el escaneo de puertos es una de las técnicas de reconocimiento más fundamentales. Un especialista necesita recorrer rangos de puertos de forma programática para identificar cuáles están abiertos, reservados o disponibles.
