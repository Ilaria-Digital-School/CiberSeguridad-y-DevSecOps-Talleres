# Ajustar la subred según sea necesario

RECORDATORIO TEÓRICO Una subred (subnet) es una subdivisión lógica de una red IP que permite organizar y segmentar el espacio de direcciones. La notación CIDR (Classless Inter-Domain Routing) expresa una dirección IP seguida de una máscara de prefijo, por ejemplo 192.168.1.0/24. La máscara determina cuántos bits están reservados para la red y cuántos para los hosts: /24 significa 24 bits para la red y 8 bits para los hosts, lo que da 2^8 - 2 = 254 hosts utilizables (se restan la dirección de red y la de broadcast). Modelo mental clave: cuanto más grande es el prefijo (ej. /28), más pequeña es la subred y menos hosts admite. A la inversa, un prefijo pequeño (ej. /16) cubre un rango enorme. Ajustar la subred significa elegir el prefijo más adecuado para un número dado de hosts, ni demasiado grande (desperdicio de IPs) ni demasiado pequeño (falta de espacio). Errores frecuentes: olvidar restar 2 direcciones no utilizables (red y broadcast), confundir la máscara de subred decimal (255.255.255.0) con la notación CIDR (/24), o superponer rangos de subred al crear múltiples subredes a partir de un bloque padre. Mini-ejemplo: necesitas alojar 30 dispositivos. 2^5 = 32, menos 2 = 30 hosts utilizables → prefijo /27 (máscara 255.255.255.224).
